# Web design rules

## Direction

- Use a quiet monochrome interface.
- Use color only for recording, success, and error states.
- Use square or small-radius controls.
- Keep the main task visible without scrolling on a laptop.
- Use a system sans-serif font for interface text.
- Use a monospace font for timing data and system status.

## Interaction

- Show one primary action.
- Show the current microphone state in text.
- Disable the primary action while transcription runs.
- Keep errors next to the primary action.
- Return keyboard focus to the primary action after a completed request.

## Acceptance

- Check the page at 390 px and 1440 px widths.
- Check keyboard operation.
- Check reduced motion.
- Check the idle, recording, transcribing, success, and error states.
